# 🎉 QR Code Generator

A simple and modern **QR Code Generator** built using **HTML**, **CSS**, and **JavaScript**. Just enter your text or URL, and instantly generate a QR code!

## 🚀 Features

* ✅ Clean and modern UI with gradient background
* ✅ Smooth animations for QR code generation
* ✅ Easy-to-use interface


## 📂 Project Structure

```
├── index.html
├── style.css
└── README.md
```

## 📌 How to Use

1. **Clone the repository**

```bash
git clone https://github.com/your-username/qr-code-generator.git
```

2. **Open the project folder**

```bash
cd qr-code-generator
```

3. **Open `index.html` in your browser**
   Simply double-click `index.html` or open it with Live Server.

4. **Enter your text or link**
   Click `Generate QR Code` and your QR code will appear instantly.

## 🛠️ Technologies Used

* HTML5
* CSS3 (with modern gradients and animations)
* Vanilla JavaScript (no libraries)
